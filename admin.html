Edit your portfolio content from any device. Changes are committed straight to JeetBangoria/protfolio and go live on GitHub Pages within a minute or two.

How do I get a token? (one-time setup)
  1. Open github.com → Settings → Fine-grained tokens
  2. Name: portfolio-admin · Expiration: 1 year
  3. Repository access: Only select repositories → protfolio
  4. Permissions → Repository permissions → Contents: Read and write
  5. Generate, copy the token, and paste it above

The token is stored only in this browser (localStorage) and sent only to api.github.com.
